# Detecting Fake Social Media Profile based on Visible Features

## Projects in this repository

| Folder | Description |
|--------|-------------|
| `dataset/`, `Other Models/`, `*.ipynb`, `*.pptx`, `*.pdf` | Fake-profile detection research: datasets, LSTM / classical ML notebooks, poster and paper. |
| [`disaster-system/`](disaster-system/README.md) | **Natural Disaster Management System** — a visualization-first Disaster Intelligence & Analytics dashboard (no login, no registration). Express + `node:sqlite` API, React + Chart.js + Leaflet client, 13 analytics modules, CSV/XLSX/JSON dataset upload, dataset analysis and dataset comparison. |

Run the disaster dashboard:

```bash
cd disaster-system
npm install && npm run build && npm start   # http://localhost:4000
npm run verify                              # end-to-end pipeline test
```
